Uygulama şifresi

Token nasıl alınır?

  1. Buraya dokunun (GitHub'a giriş yapmış olun).
  2. Token name: kuafor-panel. Expiration: No expiration.
  3. Repository access: Only select repositories > sadece bu depoyu seçin.
  4. Permissions > Repositories > Contents: Read and write.
  5. Generate token. Çıkan github_pat_... kodunu kopyalayıp yukarı yapıştırın. Kodu kimseyle paylaşmayın, sohbete yazmayın.
