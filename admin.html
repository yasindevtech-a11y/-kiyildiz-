★ ★ Yönetim Paneli

Bilgileri, fiyatları, çalışma saatlerini ve fotoğrafları buradan değiştirin.

Giriş

Anahtar sadece bu telefonda saklanır, kimseyle paylaşmayın.

Anahtarı nasıl alırım? (bir kere)

  1. Buraya dokunun (GitHub'a giriş yapmış olmalısınız).
  2. Token name: kuafor-panel yazın. Expiration: 1 year seçin.
  3. Repository access: Only select repositories seçip sadece bu depoyu seçin.
  4. Permissions > Repository permissions > Contents: Read and write yapın.
  5. Generate token'a basın, çıkan github_pat_... kodunu kopyalayıp yukarı yapıştırın.

Genel Bilgiler

İpucu: Google Haritalar'da işletmenizi aratıp çıkan adres/isim tam yazılırsa konum doğru gösterilir.
